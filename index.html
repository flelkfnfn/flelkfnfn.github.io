    A daily name game built on real birth records

    NameYear is a daily guessing game about American first names. Each round shows a class roster of six first names, three girls and three boys, that were all common in the same birth year. Slide to the year you think they were born and lock it in. The closer you get, the more points you score: up to 5,000 a day across five rounds that run from top-10 favorites to deep cuts.

    Every roster comes from the U.S. Social Security Administration's baby-name data, which counts the first names on Social Security card applications for babies born in the U.S. Answers fall between 1935 and 2025, and the slider runs from 1925. A new puzzle unlocks every day at 08:00 UTC, and everyone gets the same one.
